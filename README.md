 Complex

مكتبة Rust خفيفة للعمليات على الأعداد المركبة، ومعالجة إشارات الاتصال الرقمية باستخدام خوارزميات وصفائف مصفوفية من خلال مكتبة `nalgebra`.

## نظرة عامة

يوفر المشروع نوعًا مستقلًا باسم `Complex` لتمثيل عدد مركب من جزأين:

- `re`: الجزء الحقيقي.
- `im`: الجزء التخيلي.

تم بناء المكتبة لتكون قابلة للاستخدام كصفوف حسابية، كما توفر دوال خاصة بالحسابات الرياضية ومعالجة الإشارات في أنظمة الاتصال اللاسلكية.

## المميزات

- إنشاء الأعداد المركبة ومعالجة جزئيها الحقيقي والتخيلي.
- الجمع والضرب والقسمة، ودعم الجمع والضرب والقسمة عبر معاملات Rust.
- الضرب والقسمة باستخدام صيغ الأعداد المركبة.
- حساب المرافق `conj`.
- حساب المقدار `abs`.
- حساب الطور `arg`.
- تحويل الأعداد المركبة إلى الصيغة الأسية `exp`.
- إنشاء عدد مركب من الإحداثيات القطبية باستخدام `from_polar`.
- دعم عمليات SIMD تجريبية على معمارية `x86_64` عبر `exp_simd`.
- استخدام مصفوفات `nalgebra` ثنائية الأبعاد وتمثيلات متجهية للإشارات المستقبلة.
- استعادة الإشارة الأصلية من مصفوفة القناة والإشارة المستقبلة.
- تحويل إشارة بطول ثمانية عينات عبر `hardwarehackphy`.
- معاملات خطأ واضحة لحالة المصفوفة غير القابلة للعكس.
- اختبارات وحدة تغطي العمليات الأساسية والدوال المساعدة والدوال الأسية.

## التقنيات المستخدمة

- **Rust Edition 2024**
- **nalgebra 0.35.0**
- فئات `SMatrix` و `Vector2`
- تعليمات SSE عبر `_mm_set1_pd` و `_mm_mul_pd` و `_mm_cvtsd_f64`
- اختبارات Rust المدمجة باستخدام وحدة `#[cfg(test)]`

## مثال للاستخدام

```rust
use complex::Complex;

let z1 = Complex::new(1.0, 2.0);
let z2 = Complex::new(3.0, 4.0);

let sum = z1 + z2;
let product = z1 * z2;
let quotient = z1 / z2;
let magnitude = Complex::abs(z1);

println!("{:?}", sum);
println!("{:?}", product);
println!("{:?}", quotient);
println!("Magnitude: {}", magnitude);
```

يمكن أيضًا استخدام الدوال المسماة مباشرةً:

```rust
let sum = Complex::add(z1, z2);
let conjugate = Complex::conj(z1);
let exponential = Complex::exp(z1);
let polar = Complex::from_polar(5.0, 0.785398);
```

## استعادة الإشارة الأصلية

تعيد الدالة `recover_orignal_signal` الإشارة الأصلية من مصفوفة قناة بحجم `2 × 2` ومتجه استقبال بحجم عنصرين.

```rust
use nalgebra::{SMatrix, Vector2};
use complex::Complex;

let channel = SMatrix::<Complex, 2, 2>::new(
    Complex::new(1.0, 0.0),
    Complex::new(0.0, 0.0),
    Complex::new(0.0, 0.0),
    Complex::new(1.0, 0.0),
);

let received = Vector2::new(
    Complex::new(1.0, 2.0),
    Complex::new(3.0, -1.0),
);

let result = Complex::recover_orignal_signal(&channel, &received);
```

يرجع الخطأ `HardwareMathError::UninvertibleCannelMatrix` إذا كانت محددة مصفوفة القناة تساوي صفرًا.

## التحويل التجريبي للإشارة

تعمل الدالة `hardwarehackphy` على مقطع من ثمانية أعداد مركبة وتعيد مصفوفة ذات ثمانية مخرجات. يمكن استخدامها كبداية لتنفيذ تحويل شبيه بتحويلات الإشارة ضمن أنظمة الاتصالات.

```rust
let input = [
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
    Complex::new(1.0, 0.0),
];

let output = Complex::hardwarehackphy(&input);
```

## تحديث: ميزات إضافية

أضيفت إلى المشروع أدوات وقيم مرجعية إضافية لمعالجة الإشارات وتجربة الحسابات:

### مجموعات قيم مركبة جاهزة

- `Complex::golden_sweeq_probe()` تعيد مصفوفة ثابتة من **17** عددًا مركبًا، لاستخدامها كقيم probe أو بيانات اختبار مرجعية.
- `Complex::chatotic_golden_inverse_manifold()` تعيد مصفوفة ثابتة من **31** عددًا مركبًا، لتوفير مجموعة أخرى من القيم المرجعية المرتبطة بالتجارب.

الدالتان تُرجعان القيم المعرفة في الكود مباشرةً، ولا تستقبلان مدخلات:

```rust
let probe_values = Complex::golden_sweeq_probe();
let manifold_values = Complex::chatotic_golden_inverse_manifold();
```

### دوال حساب تجريبية

- `Complex::hw_fragility(a, b, c)` تستقبل ثلاثة أعداد مركبة وتحسب قيمة مركبة وفق صيغة تجريبية مرتبطة بحساسية/هشاشة الحسابات.
- `Complex::jump(a, b, c, d, e, f, g)` تستقبل سبعة أعداد مركبة وتحسب قيمة مركبة إضافية وفق صيغة تجريبية.
- تحتوي صيغ الدالتين على إضافات صغيرة لبعض المقامات للمساعدة على تجنب القسمة على صفر في بعض الحالات، لكنها لا تضمن أن تكون النتيجة مستقرة أو ذات معنى لكل المدخلات.

```rust
let fragility = Complex::hw_fragility(a, b, c);
let jump_value = Complex::jump(a, b, c, d, e, f, g);
```

هذه الإضافات تجريبية، ويُنصح بالتحقق من الصيغ والقيم المرجعية مقابل متطلبات التطبيق والنتائج المتوقعة قبل استخدامها في معالجة إنتاجية.

### شرح تفصيلي للإضافات

#### 1. `golden_sweeq_probe`

تنشئ هذه الدالة مجموعة ثابتة مرتبة من 17 عددًا مركبًا، وتمثل كل قيمة زوجًا `(re, im)` من نوع `f64`. لا يوجد وسيط للتحكم في عدد القيم أو محتواها، ولا تنفذ الدالة توليدًا عشوائيًا أو حسابًا وقت التشغيل؛ فهي تعيد القيم المكتوبة داخل المصدر كما هي.

يمكن تمرير العناصر إلى عمليات `Complex` الأخرى أو استخدامها كمدخلات ثابتة في تجاربك:

```rust
let probe = Complex::golden_sweeq_probe();
let first_value = probe[0];
let first_magnitude = Complex::abs(first_value);
```

ترتيب العناصر جزء من بيانات المجموعة، لذا حافظ عليه عند استخدامها للمقارنة أو إعادة إنتاج تجربة. اسم الدالة يوحي بأنها مجموعة probe، لكنه لا يحدد وحده معيارًا رياضيًا أو نتيجة متوقعة.

#### 2. `chatotic_golden_inverse_manifold`

تعيد هذه الدالة 31 عددًا مركبًا ثابتًا بترتيب محدد، وبنفس طريقة التمثيل `(re, im)`. الاسم يشير إلى manifold أو مجموعة مرجعية عكسية، لكن تنفيذ الدالة الحالي لا يحسب معكوس مصفوفة ولا ينفذ خوارزمية inverse؛ إنه يعيد قائمة أعداد ثابتة فقط.

```rust
let manifold = Complex::chatotic_golden_inverse_manifold();
let last_value = manifold[30];
```

استخدام هذه المجموعة في اختبار أو مقارنة يحتاج إلى معرفة مصدر القيم والغرض الرياضي منها؛ فذلك غير موضح داخل الدالة نفسها.

#### 3. `hw_fragility`

تأخذ الدالة ثلاثة أعداد مركبة (`a` و`b` و`c`) وتعيد عددًا مركبًا. يمكن كتابة الجزأين اللذين تحسبهما كما يلي:

```text
result.re =
    (b.re² × b.im² - a.re² × a.im²)
    / (b.re² × b.im² + 0.0001)

result.im =
    (a.im - a.re - c.re × a.im
     - 2 × (b.im × a.re - b.re × a.im))
    / (a.re² + a.im² + 0.0001)
```

تستخدم الصيغة `a.re` و`a.im` و`b.re` و`b.im` و`c.re`؛ أما `c.im` فلا يدخل في الحساب. العدد `0.0001` مضاف إلى المقامين كما في التنفيذ، لتقليل احتمال القسمة على صفر في هذين المقامين، وليس حدًا عامًا يضمن استقرار كل النتائج.

#### 4. `jump`

تأخذ الدالة سبعة أعداد مركبة (`a` إلى `g`) وتعيد عددًا مركبًا. الصيغ التالية توضح ترتيب العمليات كما ينفذها الكود:

```text
result.re =
    ((b.re - a.re) / (a.re + 0.0001))
    / (c.re × a.re × 0.004 × d.re × a.re × g.re)

result.im =
    (b.im - (a.im / (a.im + 0.0001)))
    / (e.im × d.im × f.im × g.im × d.im + 0.0001)
```

يعتمد الجزء الحقيقي على الأجزاء الحقيقية من `a` و`b` و`c` و`d` و`g`، بينما يعتمد الجزء التخيلي على الأجزاء التخيلية من `a` و`b` و`d` و`e` و`f` و`g`. لذلك لا تستخدم كل مكونات المدخلات السبعة في كل جزء من الناتج. الثابت `0.004` موجود في مقام الجزء الحقيقي، أما `0.0001` فيظهر في مقام القسمة الداخلية وفي مقام الجزء التخيلي.

**تنبيه عددي:** المقام الخارجي للجزء الحقيقي في `jump` لا يحتوي على إضافة حماية؛ فإذا كان حاصل ضرب عوامله صفرًا فقد ينتج `infinity` أو `NaN`. كما أن إضافة `0.0001` لا تمنع جميع حالات القيم غير المحدودة أو عدم الاستقرار العددي. افحص الناتج ومدخلاته، ولا تعتبر أسماء الدوال أو الثوابت ضمانًا لخصائص رياضية غير موثقة.

#### مثال يجمع التحديثات

```rust
let a = Complex::new(0.7, -0.2);
let b = Complex::new(0.4, 0.9);
let c = Complex::new(-0.3, 0.5);
let d = Complex::new(1.2, 0.8);
let e = Complex::new(0.6, 1.1);
let f = Complex::new(-0.5, 0.7);
let g = Complex::new(0.9, -0.4);

let probe = Complex::golden_sweeq_probe();
let manifold = Complex::chatotic_golden_inverse_manifold();
let fragility = Complex::hw_fragility(a, b, c);
let jump_value = Complex::jump(a, b, c, d, e, f, g);
```

القيم في المثال توضح طريقة تمرير الوسائط فقط، وليست مجموعة اختبار موثقة أو ضمانًا لنتيجة متوقعة.
